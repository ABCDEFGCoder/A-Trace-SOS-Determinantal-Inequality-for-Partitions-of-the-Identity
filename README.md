It is believed that in 2011, Yongxi Wang (xixi) designed the original problem as an exercise for his students. Three years later, a user of MSE who couldn't resolve this problem posted it and asked for help:
https://math.stackexchange.com/questions/860294/how-does-one-prove-the-determinant-inequality-det-left6a3b3c3i-n-ri

Nobody found xixi's answer to the problem, and it was much more difficult than people had expected. In the next 12 years, thousands of people viewed this problem and left many comments and discussions. Several partial results was discovered, but the critical structure leading to the final proof was still not found.

Finally, in Aug 2026, a user named Cubesteak presented a remarkable proof to the core "conjecture" using "Trace + SOS" tricks, this proof was posted under the original question on MSE.

The writer designed a general version of the original problem later. Specifically, we increased the number of matrices from 3 to m, where m is a fixed positive integer. Thus, the methods created by Cubesteak could not be applied directly, so the writer used GPT-6 Astra to explore the way.

With the help of GPT-6 Astra, a powerful improvement to the original method which can resolve the general case was discovered, and the paper was presented here.
